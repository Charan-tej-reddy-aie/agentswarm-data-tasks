# Suggest duplicate task titles

The project needs duplicate-title suggestions before displaying repeated tasks. Implement `find_duplicates(rows) -> list[list[str]]` in `dedupe_titles.py`; input is a list of objects with unique string `id` and string `title`. Input validation outside this domain is out of scope. Never mutate the input. Python 3.11+ stdlib only; no file, network or subprocess access.

Normalisation is part of the contract: Unicode NFKC, then casefold, then replace every run of Unicode decimal digits with the space-delimited token `num` (even within a word); replace each non-alphanumeric character with a space; split into tokens and take a set. This ignores case, whitespace, punctuation, numeric values, token repetitions and token order. Underscores separate tokens. Empty token sets never match, including each other. The similarity is intersection size divided by union size (Jaccard). Link two rows when similarity ≥ 0.80, including the boundary exactly. Groups are connected components of these links, so A–B and B–C place all three together even if A–C is below threshold.

Return only groups of at least two IDs, sort each group lexicographically and sort the outer list lexicographically. No ID may appear twice. Singletons are omitted. No row-order dependence is allowed. This conservative lexical definition is a baseline suggestion tool, not semantic equivalence or automatic deletion.

`fixtures/pairs.json` contains synthetic titles and exhaustive labelled ID pairs (every unordered pair); labels follow the contract. Acceptance evaluates predicted co-membership on **all** unordered pairs, with precision ≥ 0.95 and recall ≥ 0.95. When no pairs are predicted precision is 0. There are positive and negative labels. Additional contract cases require exact results on threshold boundaries, empty titles, numeric and Unicode normalisation, token ordering, transitive links, nonmutation, and reordered/randomly renamed synthetic rows. Labels are never sent to the candidate.

Acceptance: `python3 tasks/dedupe-titles/check.py --solution "$PWD/tasks/dedupe-titles/dedupe_titles.py"`. Use the issue's separate pinned trusted checkout for review. Scope: implementation file and optional implementation README. No hardcoded fixture strings, IDs, labels or access to fixtures in your solution.
